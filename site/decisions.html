Architecture Decision Records

The why, for humans and for agents

Every significant choice is an ADR so that whoever extends the lab later, human or AI, sees why things are the way they are. ADRs are immutable once accepted; a change is a new ADR that supersedes the old one. The convention itself is ADR-0001.

Conventions for contributors

Non-negotiables in AGENTS.md

Idempotent build

make up converges from any state; make down leaves nothing behind but Docker images. Never write a step that only works the first time.

No secrets in the repo

The only secret is the Anthropic API key, read at deploy time from ~/.maestro/secrets.env. Demo passwords are intentionally public and documented.

Contracts are the source of truth

Service names, ports, env vars, event and finding schemas live in docs/contracts.md. Change the doc and every consumer in the same change.

Cognition lives in skills

If an agent needs to know something about a domain, it goes in that domain's SKILL.md or its references. The Python stays domain-agnostic plumbing.

Pinned versions

Every image tag, chart version and Python dependency is pinned in one place. Bump deliberately.

The orchestrator is Maestro

No other names. Namespaces, cluster and Helm release share the maestro prefix; domain agents are <domain>-agent.
