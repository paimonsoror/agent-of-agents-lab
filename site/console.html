Watch the system think

Every component emits events to the console's hub as it works: request.received, skills.loaded, evidence.gathered, finding.returned, assessment.posted. The console animates them on the topology live, keeps a timeline, and lets anyone click a box for the play-by-play of that layer.

What the console gives an audience

Transparency into every layer

Play-by-play drawer

Click any box for that layer's narrative of the current trace in plain language: the verbatim question, who asked (subject and roles), the skill loaded, the tools discovered, each model turn with token counts, the exact question Maestro composed for each agent, and a transport block showing the MCP call, endpoint, the gateway rule that authorised it, and the caller's claims.

Live topology with product marks

Real icons for Grafana, Prometheus, Kafka and Keycloak (Simple Icons, CC0, embedded inline so offline labs work), neutral glyphs for the rest, and a small Claude badge on Maestro and each agent. Edges light as packets travel; agents turn red when implicated and green when cleared.

Scenario toggles

Apply and clear the three faults from the UI. The console performs exactly the same Kubernetes operations as scripts/scenario.sh, and derives the active state from the cluster so it is always truthful.

Ask Maestro, raise an incident

Free-text questions through /api/ask, or a one-click P1 that stands in for ServiceNow. The console authenticates as its own non-human identity, fleet-console, so every trace carries a real caller.

Timeline and replay

The hub keeps the last 200 events in a ring buffer and streams them over SSE. Replay controls re-animate the last trace, which is the fallback when the model API is slow mid-demo.

How it works, in-app

A "How it works" guide gives first-time viewers the eight-step story, each step linking to its box on the topology.

Event model

One schema from every component

Components emit JSON events to POST /api/events; the console fans them out on GET /api/stream. Each carries a trace id, a source, a kind, a one-line summary, the edge it travelled, and detail for the drawer. Maestro and the agents stay unaware of the UI: they just emit.

ADR-0009. The full schema is in docs/contracts.md.
