Cognition

Agents are plumbing. Skills are knowledge.

Nothing domain-specific lives in a prompt string in Python. Every agent loads Markdown skill bundles in the agentskills.io format, written and owned by the domain team. The cache team improves the cache agent with a pull request.

What a domain agent loads

At start, a domain agent reads its domain skill and the shared Prometheus skill fully into a cached system prompt. Files under references/ are listed by name only; the agent reads one on demand through a read_reference tool. That is the progressive-disclosure pattern from the spec: the model sees what exists, and pulls detail only when a question needs it.

Anatomy of a skill

What the APIM skill teaches its agent

Failure modes

Bad route change, backend down, auth misconfiguration, rate limiting, TLS expiry. For each: the symptom at the edge, the metric that proves it, and the first question to ask.

Exact PromQL

sum(rate(agentgateway_requests_total{status=~"5.."}[5m])) / sum(rate(agentgateway_requests_total[5m])), the rate window to use, and the threshold at which the domain is implicated.

Platform-native tools

How to read the edge gateway's declarative route config and its change annotations (maestro.io/change-id, changed-by, changed-at), so a finding names the change to roll back.

The dashboard, panel by panel

Which Grafana dashboard (domain-apim) and which panel ids to cite, so the deep link in the evidence opens on exactly the graph the agent read.

What "cleared" requires

Cleared is not "nothing looked wrong". The skill lists what the agent must positively check before it may return implicated: false with high confidence.

Recommend, never remediate

The skill tells the agent to propose the action and the evidence a human needs to approve it. Agents are read-only by design (ADR-0008).

Models

Opus conducts, Sonnet investigates

Maestro runs Claude Opus 5.5 at high effort: it has to judge which domains matter, weigh three findings against each other, and write one assessment a responder can act on.

Domain agents run Claude Sonnet 5.5 at medium effort: each has a narrow, well-specified job and a skill that tells it exactly what to check. Both use adaptive thinking, prompt caching on the skill-heavy system prompt, and structured output so findings and assessments always validate against the schema in docs/contracts.md.

Recorded in ADR-0010. The measured cost is about $0.20 per incident across the four loops.

Contract

Same shape from every domain

Every agent exposes <domain>_assess and <domain>_health over MCP and returns the same Finding schema. Maestro consolidates findings into an Assessment without knowing anything about the platforms behind them. Adding a domain never touches Maestro.

Finding     { domain, implicated, confidence, summary,
              evidence[], recommended_actions[] }
Assessment  { trace_id, summary, implicated[], cleared[],
              not_consulted[{domain, reason}], next_step }
