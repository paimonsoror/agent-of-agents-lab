The problem

Dozens of domains, one incident, no single pane of truth

Tribal knowledge

API management, caching, messaging, compute, network: each platform team knows "what to look at when it breaks", and nobody else does.

The first hour

When a P1 lands, responders spend it finding the right people and the right dashboards before anyone looks at evidence.

Agents without governance

Giving every team an AI agent helps only if calls between agents carry real identity and are allowed per caller, not shared secrets.

Labs that drift

A demo that works once is a liability. The build must converge from any state and tear down to nothing, in every lab.

What the lab demonstrates

Eight claims, each backed by running code

Federated, domain-scoped cognition

Each agent is driven by a SKILL.md bundle in the agentskills.io format for its domain, plus a shared Prometheus skill. The domain team owns the knowledge; the Python stays plumbing.

How cognition works →

Agent-to-agent transport with real identity

MCP over an open-source AI gateway. Every hop carries a Keycloak-issued JWT, and the gateway filters tools by the caller's roles before the orchestrator can even see them.

Identity and trust →

Agents act on behalf of a person, with less than that person's rights

Maestro never hands an agent the caller's badge. It asks Keycloak for a five-minute token addressed to that one agent, carrying that one role, stamped with Maestro as the carrier. Keycloak refuses what the caller never had.

On behalf of, explained →

A2A as the north star

The same gateway speaks A2A. Moving from MCP is a routing-policy change and one adapter, recorded in ADR-0004, once non-human identity is mature enough.

Monitoring every domain already sends to

Prometheus and Grafana stand in for the enterprise tool. All platforms export natively. Agents query PromQL and cite the exact Grafana panel they read.

Executive-grade visibility

The Fleet Console animates each request live and lets anyone click a box for a play-by-play: what was asked, what Maestro asked each agent, and how.

Same agents, same tools, in the IDE

Claude Code, Copilot or Cursor connect to the same gateway endpoint with the engineer's own token. What they are not entitled to, they never see.
