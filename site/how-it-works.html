What travels on the wire

Every hop is an MCP call carrying the caller's JWT

Maestro → apim_assess, via the fleet gateway

Maestro composes its own question for each agent, adding the context it has. The gateway authorises the hop with a CEL rule, then passes the token through unchanged.

MCP tools/call · Streamable HTTP
endpoint   http://agent-gateway.maestro-gateway:4000/agents/mcp
target     apim-agent  (tool apim_assess)
rule       mcp.tool.target == "apim" &&
           "domain:apim" in jwt.realm_access.roles
auth       Bearer <caller's JWT>  (propagated, never re-minted)
           sub=service-account-fleet-console
           roles=[maestro:ask, domain:apim, domain:cache, domain:messaging]
trace_id   trc-20261016-040020-8a1f
